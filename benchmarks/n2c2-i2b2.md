# n2c2 / i2b2 Clinical NLP Data

The National NLP Clinical Challenges (n2c2) and earlier i2b2 challenges provide major benchmarks for NLP over **deidentified clinical notes**.

> **Access warning:** n2c2 data are made available to approved users under a Data Use Agreement. Each user must obtain data independently through the DBMI data portal. Do **not** redistribute the datasets or upload copies to GitHub.

Official datasets page: https://n2c2.dbmi.hms.harvard.edu/data-sets

## Selected tasks

| Year | Topic | Typical tasks |
|---|---|---|
| 2006 | De-identification & smoking | PHI NER, deidentification, classification |
| 2008 | Obesity | Phenotype/comorbidity classification |
| 2009 | Medication extraction | Medication NER/attributes |
| 2010 | Concepts, assertions & relations | NER, assertion status, relation extraction |
| 2011 | Coreference | Clinical coreference |
| 2012 | Temporal relations | Event/time extraction and temporal reasoning |
| 2014 | De-identification / risk factors | PHI extraction, longitudinal risk factors |
| 2018 | ADE & medication extraction | Medication/ADE NER and relations |
| 2019 | Clinical concept normalization | Mention → UMLS/SNOMED/RxNorm concept |
| 2022+ | Later challenge tracks | See official portal for current topics |

## Key datasets used elsewhere in this catalog

### i2b2 2010
Problems, treatments and tests plus assertion and relation annotations.

### n2c2 2018 Track 2
505 MIMIC-III discharge summaries annotated for drug, strength, dosage, duration, frequency, form, route, ADE and reason.

### n2c2 2019 MCN
Clinical mentions normalized to UMLS-derived SNOMED CT / RxNorm concepts.

## Governance

Use these data only in environments consistent with the DUA. The fact that notes are deidentified does **not** make them freely redistributable.
