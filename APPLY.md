# Apply this package

This ZIP contains the intended repository-relative files.

1. Extract the ZIP.
2. Copy its contents into the root of `YPCC/medical-data`.
3. Review `git diff`.
4. Commit on a branch such as `agent/restructure-medical-data-catalog`.
5. Open a pull request to `master`.

The new `README.md` replaces the old monolithic README. The old content remains recoverable from Git history; topic pages preserve the catalog structure and historical resources.

Recommended commit message:

```text
Restructure medical data catalog and add biomedical NLP benchmarks
```
