# Preservation / Migration Note

The original repository used one large `README.md` as the complete catalog. The restructuring moves that material into topic pages so the landing page remains easy to scan.

## Preservation policy

- Existing dataset families and historical links have been retained across the topic pages.
- Older/stale URLs are intentionally labeled **Historical access** rather than silently deleted.
- Git history remains the authoritative byte-for-byte record of every prior README revision.
- No third-party dataset files are included or redistributed in this restructuring.

For a byte-for-byte view of the README immediately before this restructuring, use the Git commit immediately preceding the restructuring commit in the repository history.
